Flagged for Review

Everything below was found while rebuilding this site for GitHub Pages. Each item is either an irregularity in the uploaded project or a value that could not be confirmed from an official source — in which case it was left out of the UI or marked as unverified here instead of being guessed. The full line-by-line record, including every request URL, is in docs/verification-report.md.

Checks performed 2026-11-20 against the live MLB StatsAPI and GitHub's API.

1 · Irregularities in the uploaded repository
  • Missing assets/ directory. The initial commit contained the HTML pages, README.md and server.mjs, but no assets/css/style.css and no assets/js/*.js, so every page loaded without styling or behaviour. Session 26bf496d reconstructed them; session 8d9a5734 rewrote them against the live API and re-verified every field (see the report). Status: reconstructed, verified.
  • The original demo repository is gone. README.md points at buffedlizard55-lab/MLB-Live-PBP, and the GitHub API returns 404 for it. The original site therefore cannot be diffed against this one, so “identical to the original” is unprovable for any screen. This site is the working replacement.
  • Documents and tests referenced by the README did not exist. docs/verification-report.md, docs/scoring-changes.md, docs/api-compliance.md, docs/workflows/ and the tools/*.mjs test suite were all missing. The three documents, the two optional workflow templates and five deterministic test tools are now included; the remaining tool files named in the original README were not recovered.
  • Refresh cadences were not recoverable. The README claimed 500 ms live polling (250 ms while a review is in flight) and a 125 ms status watcher. The rebuilt client uses the cadences documented in docs/api-compliance.md (3 s live game page, 20 s scoreboard/Replay Feed, 5 s status sweep) to stay inside a reasonable request budget. Behaviour is the same: pages poll, pause when the tab is hidden, and back off on HTTP 429.
  • server.mjs cannot run on GitHub Pages. Pages serves static files only, so the optional disk persistence and server-sent-event push are inactive on the public site. The Replay Feed stores its log in the browser (localStorage) and fails open when the server endpoints are absent.

3 · Official sources used for the verified rows
  • GET /api/v1/schedule — games, records, linescore, probables, decisions, review counters
  • GET /api/v1/gameStatus — every review status code and reason (MA, MJ, NH, NJ, IH, …)
  • GET /api/v1.1/game/{gamePk}/feed/live — live state, linescore, box score, decisions, challenge counters
  • GET /api/v1/game/{gamePk}/playByPlay — play events, runner movements, review attachments
  • GET /api/v1/people/{id}/stats — season, platoon splits (vl/vr), game log
  • MLB Official Scoring Changes — who may change a ruling after a game
  • GitHub Pages publishing docs — branch publishing used by this repository
